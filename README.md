# ApexPlanet Task 2 - SecureSpace

## About the Project

SecureSpace is a responsive login and registration page created as part of my ApexPlanet 60-Day Full Stack Web Development Internship.

## Features

* Login and registration forms
* Form validation
* Password show/hide functionality
* Password confirmation validation
* Responsive design for smaller screens
* Demo login password validation

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Files

* `index.html` - Website structure
* `style.css` - Website styling and responsive layout
* `script.js` - Form interactions and validation

## Important Note

This project is a frontend demonstration. It does not provide real authentication or store user accounts.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Try the Login and Register forms.
5. Test the Show/Hide password buttons and form validation.
